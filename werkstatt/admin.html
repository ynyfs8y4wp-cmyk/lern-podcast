Dieses Konto ist kein Admin-Konto. Admins legst du im Supabase SQL Editor an (siehe README).

Du siehst Kennzahlen und Konten, aber keine Kinderprofile und keine Hörspielinhalte. Eine Ausnahme sind Hörspiele, die eine Familie selbst gemeldet hat. Jede Änderung landet im Protokoll.
